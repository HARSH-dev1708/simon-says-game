# Simon Says Game

A simple Simon Says memory game built using HTML, CSS, and JavaScript.

This project is part of my frontend development learning journey where I’m practicing JavaScript by building small interactive projects.

## Features

- Random sequence generation
- Interactive button animations
- Level progression
- User input validation

## Tech Stack

- HTML
- CSS
- JavaScript

## Run Locally

```bash
git clone https://github.com/HARSH-dev1708/simon-says-game
````

Open `index.html` in your browser.
